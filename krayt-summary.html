01 — 무엇을 하는가

서비스 하나를 배포하기 전에 사람이 손으로 하던 점검을 에이전트가 대신 수행합니다. 각 에이전트는 특정 영역(웹 침투, API 계약, LLM 취약점, 모바일, 클라우드, 공급망, 개인정보, 접근성 등)을 맡고, 같은 입력에 대해 서로 다른 각도로 검사합니다.

  • 탐지 — OWASP 4개 프레임워크(Web 2021 · API 2023 · LLM 2025 · Mobile 2024) 40개 항목에 매핑된 검사 수행.
  • 검증 — 발견을 그대로 보고하지 않고 재현 시도로 확인합니다. 재현되지 않으면 findings에서 빠집니다.
  • 증거 — PoC·요청/응답·스크린샷을 증거로 붙이고, 심각도·신뢰도를 함께 남깁니다.
  • 리포트 — 조치 방법과 함께 사람이 읽을 수 있는 형태로 정리합니다.

02 — 검증 파이프라인

1. 수집 · 범위 확인2. 에이전트 병렬 탐지3. 재현 · PoC4. 게이트 채점5. 리포트 · 조치안

게이트는 앞 단계의 산출물이 기준을 못 넘으면 다음 단계로 넘기지 않습니다. 점수만 높고 재현되지 않는 보고서, 증거가 없는 findings, 중복 발견은 여기서 걸러집니다.

04 — 공개 범위

공개

  • 구조·커버리지·모듈 수(이 페이지, 실측 기준일 명시)

Summary (EN)

KRAYT is an automated QA and security verification platform for AI services, web, and APIs. Agents detect issues, verify them by reproduction, attach proof-of-concept evidence, and gate the report before it reaches a human.

  • 797 verification modules — _run_ methods parsed from the private source on 2026-11-18 (795 agent modules across 36 agent classes + 2 pipeline runners).
  • 36 autonomous agent classes across web pentest, API contract, LLM security, mobile, cloud, supply chain, privacy, accessibility, and evidence/reporting.
  • 40 OWASP items mapped (Web 2021 · API 2023 · LLM 2025 · Mobile 2024): 33 fully implemented, 7 partial. “40/40” means no category is missing — not that every category runs at equal depth.
  • 5-stage pipeline: scope → parallel detection → reproduction/PoC → gated scoring → report.

The codebase is private; this page is the public overview. A demo or a sample report is available on request — noivan000@gmail.com.
